# Expediente del cliente (plantilla)

Copia esta carpeta como `clientes/<slug-cliente>/` para cada cliente nuevo.

| Archivo / carpeta | Contenido |
|---|---|
| `00-ficha.md` | Datos básicos, interlocutores, servicio, estado |
| `01-intake/` | Documentación aportada por el cliente (cuentas, presentaciones, datos) |
| `02-entrevistas/` | Guiones y resúmenes de entrevistas y sesiones |
| `03-plan.md` | Plan del proyecto |
| `hipotesis.md` | Hipótesis y su estado |
| `04-analisis/` | Trabajo de investigador y analista |
| `05-entregables/` | Entregables finales e informes del revisor QA |
| `registro.md` | Qué se ha hecho, cuándo y por quién |
| `decisiones.md` | Decisiones tomadas |

Los expedientes reales NO se suben al repositorio (ver `.gitignore`).
